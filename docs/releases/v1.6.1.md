# v1.6.1 · Quelle und Ausgabe auf verschiedenen Laufwerken

Fehlerkorrektur zu v1.6.0.

## Behoben

- Unter Windows brach `extract` ab, wenn die PDFs und der Ausgabeordner auf verschiedenen Laufwerken lagen, etwa Unterlagen auf `D:` und Ausgabe auf `C:`. Die Meldung lautete `path is on mount 'D:', start on mount 'C:'`. In diesem Fall steht der Quellenverweis im Markdown jetzt als absoluter Pfad; `check`, `search` und `read` arbeiten damit wie bisher.

## Aktualisieren

Plugin in Claude Code: `claude plugin marketplace update sae-l-skills`, danach `claude plugin update pdf-seitenweise-sichten@sae-l-skills`. In Codex: `codex plugin remove pdf-seitenweise-sichten@sae-l-skills`, danach erneut `codex plugin add pdf-seitenweise-sichten@sae-l-skills`. Projektkopien wie in [docs/installation.md](../installation.md) beschrieben ersetzen. Bestehende Sichtungen müssen nicht neu erzeugt werden.

Das ZIP `pdf-seitenweise-sichten-v1.6.1.zip` enthält `SKILL.md`, `LICENSE`, `ARCHIVE.json`, `scripts/` und `references/`; die separate `SHA256SUMS` prüft das ZIP.

## Nachweise und Grenzen

Der Selbsttest prüft den Fall unter Windows; ohne Korrektur schlägt er mit der genannten Meldung fehl. Realtest: sieben Vorlesungs-PDFs auf `D:` nach `C:` extrahiert, `check` ohne Fehler, Suche, Seitenlesen und Rendern geprüft, Quellordner unverändert. Unter Linux ist nur der relative Fall prüfbar. Weitere Grenzen wie in [v1.6.0](v1.6.0.md).

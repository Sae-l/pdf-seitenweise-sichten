# v1.6.0 · Plugin-Installation und genauere Suche

Diese Version macht den Skill als Plugin für Claude Code und Codex installierbar und behebt drei Fehler, durch die die Suche Inhalte übersah oder lokale Dateien in Kopien gelangten.

## Neu

- Plugin-Marketplace `sae-l-skills` im Repository. Claude Code: `/plugin install pdf-seitenweise-sichten --marketplace Sae-l/pdf-seitenweise-sichten`. Codex: `codex plugin marketplace add Sae-l/pdf-seitenweise-sichten`, danach `codex plugin add pdf-seitenweise-sichten@sae-l-skills`. Python mit `pypdfium2` und `Pillow` muss lokal vorhanden sein.
- `AGENTS.md` (mit `CLAUDE.md`-Verweis) beschreibt für KI-Agenten Installation, Prüfung und Arbeit am Repository.
- `scripts/plugin_paket.py` erzeugt das Plugin-Paket aus den Quelldateien; die CI prüft den Gleichstand. `scripts/pruefsummen.py [--fix]` prüft und erneuert `SHA256SUMS` und `skill_sha256`.
- `.gitignore` schützt vor versehentlichem Einchecken von Kursunterlagen, Sichtungen und lokalen Werkzeugdaten.

## Behoben

- **Silbentrennung:** pdfium liefert Trennstriche am Zeilenende als `U+FFFE`. Wörter wie „Codezeile“ waren dadurch nicht auffindbar. `extract` entfernt das Zeichen, vor einem Großbuchstaben setzt es einen echten Bindestrich („Commit-Nachricht“). `search` berücksichtigt das auch in bestehenden Sichtungen.
- **Lösungskapitel im Inhaltsverzeichnis:** Eine Zeile „Lösungen“ im Inhaltsverzeichnis setzte den Lösungsbeginn und blendete den restlichen Text aus. Das passiert nicht mehr. `search` meldet mit `seiten_ausgeblendet`, wie viele Seiten der Lösungsschutz ausgelassen hat.
- **Lokale Dateien in Kopien:** `install_projekt.py` und das Plugin-Paket übernahmen aus `scripts/` und `references/` auch von `.gitignore` erfasste Dateien. In einem Git-Repository werden jetzt nur nicht ignorierte Dateien kopiert.

## Aktualisieren

Bestehende Sichtungen bleiben lesbar. Für die korrigierte Trennung und den Lösungsbeginn neu in einen eigenen Ausgabeordner extrahieren; mit `--alt` bleibt der Prüfstatus erhalten. `check` meldet betroffene Sichtungen mit „Endantwortenbeginn stimmt nicht; neu extrahieren“.

Das ZIP `pdf-seitenweise-sichten-v1.6.0.zip` enthält `SKILL.md`, `LICENSE`, `ARCHIVE.json`, `scripts/` und `references/`; die separate `SHA256SUMS` prüft das ZIP. Ohne Git kopiert `install_projekt.py` weiterhin den vollständigen Ordner `references/`.

## Nachweise und Grenzen

Selbsttest, Plattformtest, Plugin-Paket, Vault und Prüfsummen laufen in der CI auf Windows und Linux. `claude plugin validate --strict` besteht für Plugin und Marketplace; die Installation wurde in isolierten Profilen von Claude Code 2.1.300 und Codex 0.163.0 geprüft. Ein Kursbestand mit sechs Gruppen wurde nach der Trennungskorrektur neu extrahiert und geprüft.

Die vollständige Agent-Endabnahme aller Oberflächen und die fachliche Prüfung sämtlicher Inhalte sind weiterhin offen. OCR ist nicht integriert; Lösungsmarker bleiben heuristisch.

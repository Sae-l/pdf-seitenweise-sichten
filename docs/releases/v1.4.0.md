# v1.4.0 · Portable Skills und Audit-Korrekturen

Diese Version enthält die Plattformbereitstellung und korrigiert beide reproduzierten Audit-Fehler mit Regressionstests.

## Änderungen

- `extract --alt` gibt übernommenen Bildern eindeutige Namen aus PDF-Dateistamm und Seitennummer. Gleichnamige alte Bilder verschiedener PDFs überschreiben einander nicht mehr; Bildbytes, Dateiendung und Sichtungsmarken bleiben erhalten.
- `check` meldet einen fehlenden `Seitenindex.md` mit Fehlerstatus.
- Portable Projektinstallation für `.agents/skills/` und `.claude/skills/`, Konfliktschutz und technische Plattformtests.
- Wiederholbare globale Installer, zusätzlicher Antigravity-CLI-Pfad sowie GitHub-Copilot-Einstieg und Setup-Workflow.
- README, Obsidian-Plan und [Plattformbericht](../plattformabnahme-v1.4.0.md) aktualisiert.

## Installation

Das ZIP `pdf-seitenweise-sichten-v1.4.0.zip` enthält `SKILL.md`, `LICENSE`, `ARCHIVE.json`, `scripts/` und `references/`. Darin sind jetzt auch Projektinstaller und Plattformtests enthalten. Die separate `SHA256SUMS` prüft das ZIP.

Nach dem Entpacken im Skill-Ordner:

```sh
python -m pip install -r scripts/requirements.txt
python scripts/install_projekt.py <vorhandener-projektordner>
```

Python 3.12 oder neuer; `reportlab` nur für Tests. Bestehende Projektkopien vor einem Update vergleichen und sichern. Für README und globale Installationsskripte das vollständige Repository bei `v1.4.0` verwenden.

## Nachweise und Grenzen

Der synthetische Selbsttest umfasst beide neuen Regressionen und die bisherigen Fälle. Windows-/Linux-CI prüft alle sechs Plattformtests, Vault, Syntax und Prüfsummen; der Release-Job wiederholt die Prüfungen vor dem Paketbau. Das erzeugte Download-Paket wird vor Veröffentlichung mit dem getaggten Quellstand verglichen.

Synthetische Lesetests in Codex Desktop und Claude Code wurden durchgeführt. **Die vollständige Endabnahme aller fünf Agenten bleibt offen**, insbesondere Antigravity, VS Code/Copilot und GitHub Copilot Cloud. Details und Grenzen stehen im Plattformbericht. Erneute reale PDF-Messungen, Effizienzgewinn und umfassende fachliche Richtigkeit sind nicht nachgewiesen.
